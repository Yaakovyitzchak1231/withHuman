# Design documents

The design documents behind this repository, as they stood when the
repository was created from the withHuman monorepo on 2026-09-24. They
describe why the product is shaped the way it is; where a document and the
code disagree, the code has moved on and the document records the
reasoning at the time. Start with `00-general-design.md`.

Documents about the hosted edition alone (billing, the AI judge block, the
chokepoint MCP gateway, organization API key issuance, enterprise sign-in)
stay with that edition.
